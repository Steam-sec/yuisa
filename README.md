# Yuisa — Bio-Cultural Nexus

**Yuisa** is a conversational AI guide — a "guardian of the Bio-Cultural Nexus" — that explores the meeting point of ethnobotany, horticulture, and the biophysics of light: how plants, light, and human culture shape each other.

## 🌿 Live App

**[Try Yuisa live](https://yuisa-bio-cultural-nexus-1012135702045.us-east1.run.app/)** — deployed on Google Cloud Run.

## About the Project

- Created and actively developed by Steam-sec in **Google AI Studio**
- A persona-driven guide that answers questions about plants and plant traditions, practical horticulture, and how light affects living systems
- Deployed as a live web app on **Google Cloud Run**

## Status

🚧 In active development. This repository is the project's home on GitHub — documentation and updates live here while the app itself is built in Google AI Studio and served from Cloud Run.
